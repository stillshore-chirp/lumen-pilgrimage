# 探索ガイド

探索の操作と、入り江・丘陵展望台・都心の70階住戸の楽しみ方をまとめます。起動手順は [README](../README.md#起動と操作) を参照してください。

## 移動と操作

Vite が表示したローカル URL を MacBook の Chrome で開くと、砂浜から入り江を見渡せます。`W` `A` `S` `D` はページを開いた直後や、描画・昼夜を切り替えた後、ファストトラベルのメニューを閉じた後も使えます。景観をクリックするか「マウス操作を開始」を押すと、マウスで視点を動かせます。画面の操作パネルに戻るには `Esc` を押します。

| 操作 | マウスとキーボード | 標準ゲームパッド（Xbox 配置） |
| --- | --- | --- |
| 移動／視点 | `W` `A` `S` `D` ／マウス | 左／右スティック |
| 地上でジャンプ | `Space` | `A` |
| 遊泳中に潜る／浮上する | `C` ／ `Space` | `B` ／ `A` |
| 地上・水面と自由飛行の切替 | `F` または画面の「自由飛行」 | `Y` |
| 飛行中の上昇／下降 | `Space` ／ `C` | `A` ／ `B` |
| 移動の加速 | `Shift` | — |
| ファストトラベル | `T` または画面の「ファストトラベル」 | — |
| 昼夜を切り替える | 画面の「昼」「夜」 | — |

ゲームパッドを接続したら、Chrome を前面にしてボタンを押してください。浜からそのまま水に入り、浅瀬は歩き、深い場所では水面を泳ぎます。遊泳中に `C`／`B` を押すと潜り、押し続けるとさらに深く移動できます。`Space`／`A` で浮上し、移動しながら岸へ戻れます。海上で飛行を解除すると、その場の水面まで降りて遊泳に移ります。

## 散策路とファストトラベル

ファストトラベルから浜、密林の休憩所、湖畔、朱の参道、稜線へ移動できます。同じメニューから丘陵展望台の中央展望デッキ、東西のテラス、2階展望デッキへ渡れます。2階へは1階の東側の階段からも上がれます。屋外のデッキから、手前の低・中層の街並み、東西の高層街区、最も高い棟が立つ遠方の都心を見渡せます。夜は窓明かりが広がり、幹線の前照灯と尾灯が街の奥へ続きます。`?world=overlook` で中央デッキ、`?world=overlook&place=upper-deck` で2階デッキを直接開けます。時間帯は移動先にも引き継がれ、URL に保存されます。

海に向かって左は波打ち際の岩棚、右は潮だまりと東の岬へ続きます。浜を背にすると林の入口に休憩所があり、岩間を抜ける道と沢を渡る道が密林を見下ろす高所で合流します。「湖・稜線」の道標から峠を越えると滝のある湖に着きます。湖を回る道から、山並みを見渡す稜線へ登れます。岩間を経由して浜から稜線へ向かう道は約1.4 kmです。

入江の西壁、対岸の東壁、潮だまりの岩棚にも滝があります。昼に浜の右側から潮だまり沿いの東散策路を少し上り、西の足元に広がる飛沫を見下ろすと虹が見えます。虹の見える位置は、太陽と飛沫に対して立つ場所を変えると移動します。

湖を奥まで回り、「朱の参道」の道標から山に入れます。架空の参詣道を歩き、楼門をくぐって前庭に出ます。杉林の二つの石段は、どちらも奥の小社へ続きます。小社前から山腹を下る道があり、稜線の散策路へ回れます。 [鳥居が連なる参詣道の参考資料](https://inari.jp/sp/map/spot_07/)

浜と稜線、林の入口、湖畔、丘陵展望台にベンチがあります。ベンチは歩いて通り抜けられます。基本の移動速度は歩行 6.4 m/s、水面の遊泳 4.1 m/s、潜水 3.6 m/s、自由飛行 20.5 m/s です。

## 都心の70階住戸

街路から246 mにある南東角の住戸です。リビングの南窓から大通りと交差点、東窓から背の異なる屋上とその先の街を見下ろせます。南側の廊下には寝室03、四畳半の茶室04、窓辺に読書席のある書斎05が並びます。通常歩行は 2.4 m/s で、机や椅子などの家具を通り抜けられます。

主寝室の東側で引戸に近づくと、画面のボタンまたは `E` で開けられます。敷居を越えると屋外バルコニーです。閉めるときは敷居から一歩離れて操作します。環境音を有効にすると、戸を開けたときに街路の音が近づき、閉めると高い音がこもります。室内とバルコニーで足音の材質も変わります。

玄関と住戸内の通行用ドアは、近づいて画面のボタンまたは `E` で開閉できます。玄関ギャラリーとリビングの境には、両側から操作できる引戸があります。開けると東側の戸袋に収まります。戸が動く範囲に立っているときは、その場から離れると動きが進みます。室内の足音は、床材に合わせたスリッパの着地と擦れです。

茶室の廊下側には引き込む襖があります。閉めると襖が廊下の光を遮り、開けると隣の部屋の光と音が開口を通ります。南窓の障子は窓辺で `E` を押すか、「住戸の操作」→「カーテン」→「茶室04」から開閉できます。閉じた障子は直射と街の眺めを遮り、紙を通った拡散光が残ります。外側のカーテンは独立して開閉できます。

窓のある居間と各個室の壁にカーテンのスイッチがあります。近づいて画面のボタンまたは `E` を押すと、その部屋の布がレールに沿って開閉します。動いている間にもう一度押すと反対に動きます。居間のスイッチは南窓の中央寄りの柱にあります。

画面上部の「住戸の操作」から、離れた部屋の照明とカーテンも操作できます。「照明」では区画を開き、器具を1灯ずつ切り替えるか、一括点灯・一括消灯を選びます。 器具を消しても、窓や開いた建具から入る光は残ります。「カーテン」では部屋を開き、壁スイッチと同じ布を開閉できます。照明スイッチに近づいて `E` を押すと、その区画の照明操作を開きます。`Esc` でメニューを閉じて探索に戻れます。

「照明」→「リビング・ダイニング」→「シアター照明」で、通常の灯りを消し、テレビ背面とローボード下に控えめな灯りを点けます。「シアター照明の色」でRGBを調整できます。モードを終了すると、それまでの器具ごとの設定に戻ります。「一括点灯」「一括消灯」でもこのモードを終了できます。日中は、必要に応じてカーテンも閉められます。

リビングの「常夜灯」と、玄関・廊下・キッチン・洗濯室・来客用WC・主寝室のバルコニー側などの足元灯は、床の近くを暖色で照らします。初期設定では夜に点灯し、昼は消灯します。「住戸の操作」→「照明」の各区画で1灯ずつ切り替えられます。

「家電・水栓」には、台所や浴室・洗面の水栓、洗濯機2台、電子レンジがあります。設備に近づいて `E` を押すと対応する操作を開けます。洗濯機は洗浄・すすぎ・脱水・乾燥から選んで運転し、いつでも停止できます。各モードは22〜60秒の短縮運転です。

電子レンジは「+10秒」「+1分」で最長30分まで設定し、「加熱開始・再開」を押します。停止した場合は残り時間から再開できます。環境音を開始すると、使っている設備の位置から給水や運転、終了の音が聞こえます。

ファストトラベルからリビング南窓、住戸の玄関、主寝室、茶室、書斎へ移動できます。`?world=residence` は夜のリビング南窓を開きます。`?world=residence&place=foyer&time=day` は昼の玄関から始まります。通常のワールド間移動では出発時の昼夜を引き継ぎます。 [間取り・茶室と書斎の詳細図 PDF](residence/residence-70f-drawings.pdf)

南窓と東バルコニーからは、街の上を遠く飛ぶ旅客機も見えます。昼は小さな機影、夜は航法灯と衝突防止灯の点滅が目印です。

## 視野角と描画

設定の「視野角」で、一人称視点の縦の視野角を 40° から 95° まで 1° 刻みで調整できます。マウス操作中は `Esc` で設定を表示します。設定値は同じブラウザでの再読み込みやワールド間の移動にも引き継がれます。「既定に戻す」を押すと、海岸と住戸では 60°、丘陵展望台では 54° に戻ります。

起動・再読み込み直後は「軽量」です。「高品質」に切り替えると、入江の海面では細波で崩れる崖の映り込み、浅瀬の砂に集まる光、波打ち際で分かれる泡が見えます。昼の森では、葉を透かす光と影に沿う木漏れ日が加わります。岩の凹凸と下草が細かくなり、湖面にも周囲の崖や空が映ります。切り替えても位置、向き、移動モードは続きます。

展望台の高品質では、敷石や笠石の目地、斜面の岩と植生、夜の足元灯と街路に広がる光を細かく描きます。住戸の高品質では家具の脚や台座に接地する影が加わり、デスクトップからは床材に応じた窓の映り込みと壁際・洗面の近接陰影も見えます。

## 環境音

「環境音を開始」を押すと、海岸を移動しながら、その場の水際で波が寄せて返る音を聞けます。岩を挟むと直接音の高域が弱まり、岩壁や開口から反射や回り込みが届きます。砂、岩、林床で足音が変わり、浅瀬では水はねが鳴ります。潜水中は外の音がこもります。密林の鳥、虫、小川、落水にも、それぞれ発音位置があります。両描画設定で同じ音響処理を使います。ブラウザや OS が音声を中断したときは「環境音を再開」を押してください。

浜や上空にはウミネコ、林と参道にはメジロ、ウグイス、クロツグミがいます。湖ではカルガモが泳いで餌を探します。野外録音の鳥声は、近くの止まり木や飛行中の鳥に加え、林の奥や峠、稜線からも間を置いて届きます。遠い声は小さくなり、間に岩壁があると高い音がこもります。湖の滝音は水が落ちる位置から聞こえます。

丘陵展望台でも「環境音を開始」を押すと、盆地の幹線から遠い交通音が聞こえます。丘に遮られる方向や遠い道路の音はこもり、視点を回すと聞こえる向きも変わります。昼は近くの低木から時折鳥が鳴きます。夜は車の音が弱まり、デッキの正面にある草地と斜面からコオロギの声が届きます。

## 仮想モニター

1. MacのChromeで景観を開き、「仮想モニター」から「配信画面を開く」を押します。配信画面では「画面共有を開始」を押し、Chromeのダイアログで映したい画面、ウィンドウ、またはタブを選びます。
2. 元の景観タブの「接続コード」に、配信画面に表示されたコードを入力します。有効時間は発行から2分です。両画面の確認番号を照合し、配信画面で「接続を許可」を押すと映像が届きます。
3. 音声付きで共有したときは、視聴側で「モニター音を有効にする」を押します。「モニター音量」「モニター音をミュート」「モニターの音響」は環境音の操作から独立しています。
4. 終えるときは配信側で「共有を停止」を押すか、視聴側で「切断」を押します。再接続には新しい共有とコードが必要です。別ワールドへ渡るとページを読み直すため、移動先で接続し直してください。

「モニターを表示」で視界の前方に映像面を呼び出せます。「配置を編集」を押したら、移動・回転・拡大縮小を選んで映像面をドラッグします。拡大縮小は右や上へドラッグすると拡大します。編集を終えるには `Esc` を押します。「モニターを隠す」は映像面の表示を切り替えます。「位置・サイズを戻す」は今の視点を基準に置き直します。

70階住戸のリビングでは、窓向きソファの背に沿ってホームシアター向きの席を配置しています。ファストトラベルの「リビングのホームシアター」で、壁に掛けた130V型相当のテレビの前へ移動できます。「仮想モニター」の「表示先」で「リビングのテレビ」を選び、「テレビに表示」を押すと、接続中の映像がテレビに映ります。浮遊モニターへ戻すときも同じ接続を使います。

視聴側の「ステレオ」は頭部固定です。「空間音響」では、モニターを動かしたり画面の横や後ろに回ったりすると、音の方向と強さが変わります。PCの物理的な出力機器はOSの設定に従います。

住戸では「リビングのテレビから」と「リビングの5.1chスピーカー」も選べます。スピーカー出力では、ステレオ入力を前方左右に配分し、6チャンネル入力の各成分を前・後・中央と低音用のスピーカーに割り振ります。部屋の中での位置と顔の向きによって左右の聞こえ方が変わります。

| 配信画面の設定 | 音声の経路 |
| --- | --- |
| PC側のみ | 視聴先への音声送信を止め、PCで再生します。共有タブのPC再生を止めていた場合は、共有対象を選び直すと再開します。 |
| VR側のみ | 対応ブラウザで音声付きのタブを共有し、共有タブのローカル再生抑止が設定されたときに使えます。ウィンドウや画面全体の共有では「両方」で再生します。 |
| 両方 | 選んだ対象の音声をPCと視聴先で再生します。 |

Chromeの共有ダイアログで音声共有が選べる場合に音声を送れます。音声トラックが渡らない共有対象は映像のみです。同じPCで画面全体の音声を共有すると、視聴側の音が共有元へ戻ります。その場合は「PC側のみ」、視聴側のミュート、または音を出すタブ単体の共有を使ってください。[Chromeのローカル再生抑止](https://developer.chrome.com/blog/screen-sharing-improvements-in-chrome-109#suppress_local_audio_playback)

VRで見る場合はヘッドセットのブラウザで接続と音声の準備を済ませ、「VRで見る」を押します。コントローラーは照準を映像面に向けてグリップを握ります。手の追跡では親指と人差し指でつまみます。片手で移動・回転し、両手で間隔を変えて拡縮できます。配置を固定するには手を離してください。映像面を見失ったときはヘッドセットのメニューからVRを終了し、開いたパネルで「位置・サイズを戻す」を押します。[別端末と実機の確認手順](verification.md#仮想モニターの実機確認)
