# 十三弦箏の縮約物理モデル

対象は[湖畔の広間](lake-hall-design.md)の39秒の独自曲で使う単音の乾音です。楽器の生成、演奏と調弦、天井スピーカーを通る再生を分け、ここでは生成モデルの根拠、仮定、数値的な成立条件を扱います。主Issueは [#275](https://github.com/stillshore-chirp/lumen-pilgrimage/issues/275) です。

このモデルは実測済みの箏の複製ではありません。一次資料にある楽器構造と低域共鳴を使い、未入手の橋のアドミタンス、減衰、放射を設計値で補った縮約モデルです。人間の聴感による自然さの判定は独立した受け入れ条件です。

## 現行音源の問題

変更前の `lakeKotoScore.ts` は24 kHz、18部分音、2.9秒で打ち切る弦を使い、胴の正弦波6個と短いノイズを各音の開始で独立に発火させていました。

| 箇所 | 物理上の不足 | 新モデルの対応 |
| --- | --- | --- |
| 弦 | 振幅の `sin(nπp)/n^0.8` が変位・橋の力・放射のどれか不明。一定の非調和率を全音域へ適用。 | 張力、線密度、長さ、実効曲げ剛性から弦のモードを計算し、三角形の初期変位を投影する。 |
| 爪 | ノイズが弦・胴へ力を伝えず、音量以外の接触条件がない。 | 有限接触時間で初期変位の角を丸め、強弱で変位量と高域の励起を変える。白色ノイズを直接混ぜない。 |
| 柱と胴 | 胴が弦の運動と無関係に鳴り、弦のエネルギーを受け取らない。 | 柱の移動に追従する弦の拘束モードを使い、質量行列を介して弦と胴を双方向に結ぶ。 |
| 押し手 | 正弦波の周波数を一律に曲げる。 | 張力を変え、同じ変位・速度状態を継続して積分する。 |
| 消音・余韻 | 全音に同じ固定打ち切りがある。 | 指による追加損失と、音域別の周波数依存損失を使う。標準の単音長は6秒。 |
| 強弱・反復 | 曲の最後のピーク正規化に絶対強弱が依存する。 | 単音は固定ゲイン。seedが同じなら同じ接触条件、異なれば小さい接触位置・方向・形状の変化を再現する。 |

`lakeKoto.ts` の天井12スピーカーは同じモノ音源を配る再生層です。その音量・HRTF・ループの検証結果を楽器音色の合格と読み替えません。

## 弦、柱、胴の方程式

発音区間の変位を、固定端弦の座標qₙと橋の移動bで表します。

`u(x,t) = Σ qₙ(t) sin(nπx/L) + (x/L)b(t)`、`b(t) = Σ φⱼ zⱼ(t)`。

qₙ、zⱼはm、x、Lもmです。φⱼは橋位置での胴モード形状です。弦モードの質量はμL/2、胴の有効質量はMⱼとし、実装ではそれぞれの平方根で座標を正規化します。ωₙはrad/sです。

`ωₙ² = [T(nπ/L)² + EI(nπ/L)⁴]/μ`。

`B = π²EI/(TL²)` とすれば、非調和率の理論比較は `fₙ/f₁ = n√[(1+Bn²)/(1+B)]` です。全弦でB一定にはしません。

三角形に変位させて解放した初期条件は、演奏者側の固定端（竜角）からの距離比pに対し `qₙ(0)=2y₀sin(nπp)/[π²n²p(1−p)]`。固定端はx=0、可動柱はx=Lです。通常のp=0.10–0.14は固定端近傍の撥弦を表し、可動柱近傍へ対称移動して扱いません。両端を入れ替えると偶数モードの位相が変わり、柱への連成出力にも影響するためです。これに有限接触の形状係数 `exp[−(2πfₙτ)²/2]` を掛けます。初期速度はゼロ、胴も静止から始めます。解放前の接触摩擦と静的な胴変形は近似対象外です。

質量正規化後、aは弦成分だけ、gは胴成分だけを持つベクトルです。

`aₙ = √(2μL)(−1)ⁿ⁺¹/(nπ)`、`gⱼ = φⱼ/√Mⱼ`、`c=μL/3`、`k=T/L`。

各偏極の連成系は次の行列を使います。

連続系は `M = I + agᵀ + gaᵀ + cggᵀ`、`K = diag(ω²) + kggᵀ`、`C = diag(2σ)` です。実装では後述の複素極の写像で、K/Cの孤立モードの対角成分をともに補正します。

`M q̈ + C q̇ + Kq = 0`。

橋の変位・速度が弦に戻る項がMにあるため、胴の音を別に加える一方向フィルタではありません。Cは弦と胴で別の値を維持し、結合系の減衰を事後の単一包絡へ押し込みません。二つの偏極は別々の有効質量と減衰を持ちますが、偏極間のねじり・摩擦は未実装です。

### 押し手、消音、放射

押し手は0.10–0.36秒の5次smoothstepで目標へ向かいます。平均律の目標比 `R=2^(semitones/12)` に対し、曲げ剛性を含む基本音を保つため `T=(T₀+π²EI/L²)R²−π²EI/L²` を使います。変位・速度をリセットせず、張力変更による外部の仕事を許します。爪の変位による一時的な非線形張力、指・柱上の動摩擦、押し戻しは未校正です。

`dampAt` 以後12 msで弦の損失を立ち上げ、追加減衰率は `ln(1000)/0.10 s⁻¹`。これは孤立弦の振幅を約0.10秒で60 dB下げる設計です。胴の状態はリセットしません。

放射は胴モードの速度の線形結合から出し、橋の結合係数とは別の重みを使います。sample iには更新前の同じ時刻tᵢの速度を出力し、その後に状態をtᵢ₊₁へ進めます。中点速度をtᵢの出力として扱うと、サンプルレートで異なる半刻みの時刻差が生じます。35 HzのDC除去と13.5 kHzの2次Butterworthローパスを通します（低いサンプルレートではカットオフを0.40fs以下にする）。これは音孔・曲面・聴取方向を解く空間放射モデルではなく、乾音の一つの投影です。湖畔での空間再生は `lakeKoto.ts` 側の責務です。

## 数値安定性と予測可能な検証

刻みをh=1/sampleRate秒とし、中点速度wを次式で求めます。

`[M+hC/2+h²K/4]w = Mv−hKq/2`、`q′=q+hw`、`v′=2w−v`。

対角部分とrank 2更新の逆行列をWoodbury式で計算します。行列の大きな固有値計算やN×Nの逆行列を毎サンプル作りません。固定係数の系では、蓄積エネルギー `E=(vᵀMv+qᵀKq)/2` の変化は厳密演算で `E′−E=−h wᵀCw≤0` です。

Mが正定である理由は、有限個の弦モードについて `Σaₙ² < μL/3=c` が成立することです。Kは正の対角と非負rank 1項、Cは非負の対角です。したがって固定係数下の陰的中点法には陽解法のCFL上限はありません。ただし数値安定と周波数・減衰の正確さは別です。

孤立モードの連続系の目標極を `p=−σ±j√(ω₀²−σ²)`（rad/s）、h=1/fsとします。先に `z=exp(ph)` を計算し、双一次変換を逆に使って `s*=2fs(z−1)/(z+1)` と置き、実装用の係数を `K*=|s*|²`、`C*=−2Re(s*)` とします。これで孤立した離散モードの極は目標のzに一致し、周波数と振幅減衰をともに合わせられます。σ=0では従来の `ω*=2fs tan(πf/fs)` に一致します。σ>0かつ対象範囲の不足減衰モードではK*>0、C*>0です。実装は低域での桁落ちを避ける正の二乗和と `expm1` を使います。

周波数だけをprewarpしてCを変えない場合、孤立した高域モードの実効減衰は概ね `σcos²(πf/fs)` へ弱まります。例えば14.08 kHz・目標σ=48.26 s⁻¹の孤立モードは、その方法では48 kHz時に17.64 s⁻¹程度となります。本実装はこの系統差をK/C両方の写像で補正します。周波数の一致だけで減衰まで正確と判定しません。

極の一致は孤立した各モードの性質であり、低rankの質量結合と橋の剛性を加えた系全体の連続時間解との完全一致ではありません。連成後の音高・高域・位相は48/96/192 kHzの出力で確認します。診断用エネルギーはこの補正後のKを使う縮約系のJであり、元の連続弦の厳密なエネルギー実測値ではありません。押し手では張力の仕事でKが変わり、消音でも極の補正のためKが微小に変わり得ます。固定係数の証明だけで処理を済ませず、消音中の非増加も回帰で確認します。

生成する弦モードは押し手の最大上昇後も `min(18 kHz,0.38fs)` 未満、上限96個です。これにより押し手でNyquistを越える部分音を後から折り返しません。接触形状のガウス係数は高域の励起をさらに下げますが、無限の帯域阻止ではありません。モード切り捨てによるスペクトルの誤差や、16サンプルごとの時間変化係数による側帯波の完全な上限保証とは区別します。48 kHzと96 kHzの同一条件レンダーの差を確認し、差全体をalias量と呼ばず、離散連成・放射フィルタの周波数応答・接触帯域の寄与も含む収束指標として扱います。

恒久回帰は [`koto-physical.test.mjs`](../../scripts/koto-physical.test.mjs) です。低rank更新を独立に組み立てた密行列の解と比較し、初期静止の胴へのエネルギー伝達、撥弦位置の向き、孤立モードの周波数と高域の複素減衰極、固定張力の受動性、強弱、押し手、消音中のエネルギー、seed、入力の範囲を検査します。

```sh
node --test scripts/koto-physical.test.mjs
```

音声出力と48/96 kHzの比較は[測定と比較試聴](koto-measurements.md)の条件・CLIを使います。ここで定める物理・数値の予測と、実波形の音高・帯域・減衰・処理時間の記録を分けて追跡します。

## APIと再現

```ts
import { renderPhysicalKotoNote } from './kotoPhysicalModel';

const samples = renderPhysicalKotoNote({
  frequency: 392, velocity: 0.70, pluckPosition: 0.12,
  pressSemitones: 1, dampAt: 2.4, duration: 6, seed: 275,
}, 48000);
```

戻り値はモノラルの `Float32Array`、入力のfrequencyはHz、時間は秒、pluckPositionは固定端からの発音長比です。診断用の `diagnostics` オブジェクトを渡すと初期・最大・最終エネルギー、16サンプルごとの最大増加率、弦モード数を取得できます。診断の有無は音声の値を変えません。単音のピークを1にそろえず、曲と比較UI側でクリップしない固定ゲインを決めます。

## 権利確認と残る範囲

外部録音、学習済み係数、論文のコード・図・CTモデルは採用せず、公開された運動方程式を独自に実装します。これは自作だけを理由とした権利保証ではありません。

関連検索で [US7915515B2の公報・請求項1,12–20](https://patents.google.com/patent/US7915515B2/en) を確認しました。請求項1は鍵盤と弦のある楽器、実演者のトリガーから実時間に生成する装置、事前処理で生成する減衰正弦部分音の係数を含みます。本件は箏のオフラインPCM生成、連成した運動方程式の直接積分であり、点群からのmodal係数補間、鍵盤、ハンマーの発音を採用しません。公報の表示は現在の公式権利状態の確認に代わらず、特許網羅調査や各国での実施自由を保証しません。対象用途を実時間の汎用鍵盤音源へ拡張する場合は再調査が必要です。

現物の橋アドミタンス・放射測定、編糸の曲げ剛性、接触摩擦、13弦相互のcross-admittanceは未入手です。各単音は励起された一本の弦と胴を解き、多弦の演奏は単音出力を重ね合わせます。全13弦の共鳴伝達、柱間の異なる伝達経路まで解いたという主張はしません。最終的な自然さは録音と音量をそろえた人間の試聴で判定します。
