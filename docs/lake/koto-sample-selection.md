# 箏実録音の候補比較と採用条件

本書は[Issue #275](https://github.com/stillshore-chirp/lumen-pilgrimage/issues/275)の実録音探索、候補ごとの事実と不確実性、加工・配布の判断を記録します。恒久ルールは[外部音声の採用基準](../assets.md#外部音声の採用基準)、ファイル単位の記録は[音声台帳](../../assets/lake-audio/sample-manifest.json)、配布条件は[音声クレジット](../../public/lake-audio/ATTRIBUTION.md)を参照してください。

## 今回の要件と判定範囲

新規外部音声は、CC0 1.0の明示と、制作元・録音・実演・楽曲・第三者権利・倫理について合理的な確認ができるものに限ります。十三弦箏の単音実録音を最優先とし、既存の独自39秒曲、物理合成の研究開発、音色・演奏・空間の品質評価を継続します。この案件限定のCC0条件を、他案件の全ライセンスの禁止や既存素材の撤去へ拡張しません。

「箏の実録音候補」「十三弦と確認できた録音」「加工して配布する単音」「人間が合格と評価した音源」は別の状態です。圧縮プレビューや混ざった音を取得できたというだけで、十三弦単音の採用や最終音質を合格にしません。

## 取得できた音と同一性

Session 2/3のページは、原WAVのボタンにログインが必要と表示する一方、Share url用のHTML属性 `data-static-file-url` に公式CDNのhq MP3を公開しています。公開URLの音声を研究用ステージへ取得し、ログイン・アカウント作成・認証回避・非公開URLの推測を行っていません。これらは96 kHz・24-bit原WAVではありません。

公開CDNの転送が遅いため、取得は40秒・先頭2,000,000 bytesのRange要求で区切りました。両方ともcurl exit 28で終了し、得られた先頭部分だけを保存しました。MP3ヘッダーの全曲時間を取得済みの長さと見なさず、実際にデコードできたフレーム数で扱います。ファイルが途切れる末尾を音の自然な減衰や消音の証拠に使いません。

| `freesound-365215` | 1,802,240 / `5c9f8925cee5618525d3dbc2a70e8bab956b3de55b9fc79dd52adcebf2e2cce1` | 48 kHz・stereo PCM16、3,653,039 frames、76.104979秒、FFmpeg exit 0。 |
| `freesound-365242` | 1,724,416 / `c59278af17194f544c1f2a364ffeadccad22a36c8af356b7215478266396c984` | 48 kHz・stereo PCM16、3,566,639 frames、74.304979秒、FFmpeg exit 0。 |

確認時刻、元ページの表示とhash、取得URL、デコードhash、ツール版は[台帳](../../assets/lake-audio/sample-manifest.json)を正本とします。取得した元プレビューと全即興録音は公開・配布ツリーに含めません。部分取得の再実行では通信速度によりbytesが変わり得るため、同じhashになるとは保証しません。

厳密な同一prefixを再取得する確認は、Session 2が通信切断（curl exit 56・0 bytes）、Session 3が時間切れ（exit 28・188,416 bytes）で未達でした。元取得物は保全し、成功した再ダウンロードと記録しません。一方、保持したdecode入力のSHA-256を固定した[単音加工の再生成](koto-sample-processing.md#編集元と再現)では、5 WAVとbankがバイト単位で一致しました。取得の再現と同じ入力からの加工再現を区別します。続行する担当者は出典の条件を再照合し、新しい取得物のhashと加工範囲を記録します。

## 五単音の権利・倫理判定

以下の5区間は、加工単音の公開リポジトリ同梱、独自曲の生成、物理方式と組み合わせた暫定的な技術利用に採用可と判断します。個別CC0 1.0と本人の自己即興・録音公開の説明を根拠にし、短い音だから権利確認が不要という判断はしません。元録音のフレーズ・発音順・即興の間合いは転用しません。

採用対象は `low-151`、`mid-319`、`mid-452`、`high-640`、`high-792` の5単音です。出典の秒・フレーム範囲、推定基音、長さ、チャンネル、フェードと共通gainは[加工正本](koto-sample-processing.md#編集元と再現)と[同梱bank](../../public/lake-audio/samples/bank.json)を参照します。出力5 WAVのhash・bytes・フレーム数・48 kHz mono PCM16を実ファイルで照合済みで、合計3.093秒・297,148 bytesです。原録音全体を無加工で再配布せず、本作の加工・再生成に必要な入力として同梱します。

元ページに既成曲や第三者音源からの切出しを示す記述はなく、本人は加工・リミックスを歓迎しています。単音を調音して独自曲に配置する利用と、3,500 Hz以上のアタックを短時間利用して物理合成へつなぐ加工は、この制作意図に整合すると判断します。作者が推薦・参加・共同制作したという表示は付けません。5単音そのものを独立した商品用素材集として売る利用は今回の対象にしません。

単音候補の自動screenは、直前の静かな区間、推定発音位置、初期73–253 msの基音周辺の倍音energy比98.46–99.91%を利用しています。これは発音・倍音構造に関する補助情報であり、声・他音楽・第三者実演が存在しない証明ではありません。人間による混入確認・聴感評価は未実施です。一次出典と自動screenに矛盾する具体的兆候は現時点で確認していませんが、後に第三者音・特徴的なフレーズ等の混入が分かったcutは不採用へ戻し、依存する生成音を更新します。

初回5根による純サンプル方式は、押し手を含む最大調音幅±5半音の範囲に限り、A3・B♭3を含む全39秒曲を成立済みとはしませんでした。初回hybridは録音の高域attackを約75–145 msで物理方式へ渡す比較履歴です。追加240 Hzを含む現在の4根方式とは区別します。人間が自然な箏と評価したこと、十三弦の実録音と確認したこと、原WAVを取得したことはいずれも意味しません。[台帳](../../assets/lake-audio/sample-manifest.json)の `adopted` は、この権利・倫理と加工単音の同梱の判定です。5 WAVと共有bank、加工・比較・演奏コードを実ファイルへ対応付けています。同梱生成曲も、次節の出力と元出典IDへ登録しています。

## 追加240 Hzと現在の配送

追加の `low-240` は確認済み365242の38.769–39.580秒、channel 0、元decode SHA `133eff375b227d0d2480bec544cbaa535994adf8cbeb5708235d8c73c5c47430` からの切出しです。0.811秒、DC除去・0.5 ms開始fade・55 ms終端fade・初回bankと共通のgainを含み、[原6根bank](../../public/lake-audio/samples/recorded-bank.json)へ元フレームと加工値を残します。新規の録音者や出典は採用していません。

最大peakが約481 Hzでも、240/720/1200 Hzの系列と周期が240 Hz rootを支持したため、この根を使用します。これらは音高screenであり、単一弦、第三者音の不存在、実物十三弦、録音者の権利を追加で証明するものではありません。権利・倫理は同じ原出典のCC0と本人の自己即興・加工希望の根拠を再利用します。

現在は240/452/638/792 Hzの4根を使います。[処理bank](../../public/lake-audio/samples/sustain/bank.json)は、240のtailの要求1.175倍、452/638の要求3倍を上限とした有限atempo処理、792の時間伸長なし、各実出力長・hashを区別して記録します。有限時間加工は録音されなかった自然な余韻の回復ではありません。[相対励振FIR](../../src/coast/world/lake/kotoExcitationColor.ts)は仮定したτ–velocity関係による自作補正で、実測velocity層や同定body IRではありません。FFmpegはオフライン処理ツールだけに使用し、GPL buildの実行ファイルやライブラリを配布せず、CC0原録音とは別に版・hash・commandを台帳へ記録します。

[同梱39秒曲](../../public/lake-audio/koto-performance.wav)は `sample-sustain-color` / 48 kHz・mono・24-bit PCMです。[生成記録](../../assets/lake-audio/production.json)の元出典ID、入力hash、全48発音、相対FIR44発音、fallbackなしを実配布hashへ対応付けます。原即興のフレーズや音列は転用せず、[独自の演奏入力](../../src/coast/world/lake/kotoPerformance.ts)を使います。初回hybridと当時の入力・生成記録は[履歴](../../assets/lake-audio/history/hybrid96-production.json)へ残し、現在の採用と混同しません。

所有者は今回の改良turnをここで区切り配送することを指示しました。これは最終の自然さ・一つの箏としての音色が人間に合格と評価された記録ではありません。以前のhybrid等への否定的な音色評価は保持します。十三弦の個体、録音強弱層、収音条件の同一性、人間による第三者混入確認は未確認であり、終了合意を理由に確認済みへ変更しません。詳細な配布・加工対応は[クレジット](../../public/lake-audio/ATTRIBUTION.md)と[台帳](../../assets/lake-audio/sample-manifest.json)を参照します。

## 加工・配布・使用の設計

上記の権利・倫理判定に加え、次の条件を満たした加工物を実際の配布・利用へ対応付けます。技術上の採用と人間の最終音質合格は別に判定します。

1. 振幅包絡とスペクトルで、立ち上がり前後・持続・減衰が他の弦や雑音に埋もれない候補を選びます。単音と判断できない区間、特徴的な即興フレーズ、会話等の第三者音は採りません。
2. 出典時刻、入力hash、切出し長、音高・許容調音幅、フィルター・正規化・前後フェード、チャンネル処理、再サンプリングと出力形式を記録します。圧縮や収録条件に由来する制約を消したと断定しません。
3. 同じ音量・音域・奏法条件で物理合成、実録音利用、ハイブリッドを実レンダーし、立ち上がり、倍音と減衰、押し手・消音、重なり、変調・ループ・空間処理、性能を比較します。音量を大きくした効果を音質向上と取り違えません。
4. 配布するのは有用性を確認した加工物と、それを用いた独自演奏です。無加工の即興録音を素材集として丸ごと同梱せず、実使用に必要な範囲にします。作者の推薦や共同制作に見える表現を付けません。
5. 採用したファイルを `distribution`、使用コードを `usage`、加工・検証を各該当欄へ反映し、[クレジット](../../public/lake-audio/ATTRIBUTION.md)を更新します。人間の聴感未実施、弦数未確認、使えない奏法や音域は保持します。外部音声を使っても、全研究・制作・検証の受け入れ条件は省略しません。

## 残る確認

十三弦の明示、単音ごとの混入・音域・爪と指・減衰・圧縮への適合、人間の自然さ評価が未確定です。本人の記述から実演の主体と録音公開の意思は追えますが、録音時の全員・権利の完全な連鎖を独立に立証したものではありません。合理的な調査・切出し評価で解消できない権利・倫理懸念、または品質不適合がある区間は採用しません。
