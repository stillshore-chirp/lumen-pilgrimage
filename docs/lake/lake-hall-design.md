# 湖畔の広間の設計

畳敷きの大きな広間から、岩峰に囲まれた湖を見渡す。正面の低卓は水と空を見る位置を示し、左右の木床の縁側からは水際を見下ろせる。自然の動きは水、雲、鳥、魚の異なる時間尺度で見え、夜は室内と水辺の輪郭の向こうに星空が広がる。

## 写真と照合する視点

参照画像の比率は2944:1648。手前の木格子と畳を額縁として、左右の岩壁、低い岸と湖、奥へ重なる雲、中央の石の環を配置する。遠い白い帯は浅い砂礫の岸、背後の直線的な輪郭は霞む遠景の構造物として解釈した。横に見切れる広間と外の地形、夜間と音は設計上補った。

位置比較のカメラは `(0, 1.65, 7)` m、正面 `-z`、上向き0.135 rad、縦視野角52°。広間の床を `y=0` とする。眼高と視野角を定めて窓枠と奥岸の投影を合わせ、距離の異なる地形を置く。単一画像からの寸法はカメラと基準面の仮定に依存する。図の比率は写真に対応する制作目標として使う。 [Criminisi・Reid・Zisserman, Single View Metrology](https://robots.ox.ac.uk/~vgg/publications/1999/Criminisi99/)

## 平面と移動

[寸法](../../src/coast/world/lake/lakeLayout.ts)を形状と[移動判定](../../src/coast/world/lake/lakeNavigation.ts)で共有する。広間は幅43.2 m、奥行き19.4 m。中央窓は `|x|≤16.65` m。窓の両端で板張りの縁側へつながり、`z=-11.6` mまで張り出す。畳、木床、縁側を同じ床高にそろえる。窓、低卓、周囲の縁は歩行を止める。広間と外気の境界に板床を置く縁側の構成を採った。 [JAANUS・縁側](https://www.aisf.or.jp/~jaanus/deta/e/engawa.htm)

大きな屋根と床の間の窓面を細い縦枠と上横枠で納め、畳の暗い縁と格子の間隔で室内の距離を読めるようにする。板床と木格子は木目、畳は織り目の方向と反射の違いを持たせる。窓の手前に物を密集させず、移動中に島と雲の重なりが変化する空間とする。

## 光、空と湖

昼は右手上方からの光で岩の割れ目と松の輪郭を出す。遠方には青灰色の空気遠近を増やし、岸の白い帯、岩の環、雲が重なる。積雲を異なる距離、速度と高さで移流させ、環の裾と背後を通る層を設ける。移動は固定視点の時間差画像で追う。天空色は既存の大気散乱モデルを使い、雲は別レイヤーとして配置する。 [Bruneton・Neyret, Precomputed Atmospheric Scattering](https://ebruneton.github.io/precomputed_atmospheric_scattering/index.html)

夜は暗い天空に光量差のある星を分布させ、天の川は淡い帯で見えるようにする。雲が通過すれば背後の星が隠れ、遠くの空と水辺の輪郭は読み取れる。屋内の弱い灯りは眺めを邪魔しない範囲に置く。 [NASA・暗い場所での星空の見え方](https://science.nasa.gov/solar-system/skywatching/how-to-find-good-places-to-stargaze/)

正面の低い視線では水が天空と岩峰を映す。縁側で水を見下ろすと、浅瀬の水色、魚の輪郭、さざ波の移動が見分けられることを確かめる。遠い反射と近い透過は同じ水面を違う角度から見た結果として扱う。通常画面と模擬WebXRでは、カメラ位置を変えて反射と水際の安定を確認する。

## 生き物と音

魚は両側の縁側から見下ろせる浅い水域に小群で泳ぎ、姿勢の変化と尾の動きを持たせる。鳥は谷に沿って少数で飛び、羽ばたきと滑空で速度や向きの変化を見せる。夜は静かな間を長く取る。

湖岸の水と間を空けた鳥の声を空間に置く。中央の室内と、窓端を回って出る左右の縁側で、開口、ガラスによる遮蔽、距離と聞こえる方向を使う。比較時は音源と全体音量を固定する。回折・遮蔽に応じて周波数帯が変化する知見は、壁越しと開口側の経路を描き分ける判断に使う。 [Schisslerら・回折の経路と応答、図5と図11](https://www.carlschissler.com/downloads/publications/siggraph2014.pdf)

## 素材と確認方法

参照画像は構図と制作寸法を検討するために読み取った。配布素材はプロジェクト内の出典を確認した木、岩、雲、録音と、このワールド用に実装する立体や手続き素材を使用する。木・石・雲・録音の利用条件は各素材の記録を参照する。研究資料は設計の根拠として参照する。 [木材](../../public/residence-materials/ATTRIBUTION.md) · [岩と雲](../../public/coast-materials/ATTRIBUTION.md) · [録音](../../public/coast-audio/ATTRIBUTION.md)

初回提示では、正面の昼・夜、左右の縁側、同じ視点の時間差画像、屋内から縁側を通る操作を照合する。舞台全体が見える視点では描画の負荷を測る。音は環境音をオンにして場所を変え、設定による変化を確かめる。 [確認手順](../verification.md)
