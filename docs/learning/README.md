# 歩ける空間の設計

商業施設の吹抜けに立つと、階段の上端までの距離が見え、欄干を越えて別の階の気配が伝わる。床を横切れば、石に映った照明が移動し、足音の響きも変わる。こうした現象を設計に取り込むには、空間の形、表面で起きる反射、目と耳に届く情報の関係を理解する必要がある。

本書は、参照写真から空間を読み取り、人が移動しても成立する仮想建築を設計するための技術書である。建築、造形、照明、音響をそれぞれ基礎から扱い、各分野の判断が他の分野に及ぼす影響を吹抜けの事例で追う。図と数値例の空間は本書のために作図・設定した。式の変数には単位と成立条件を示す。

## 記述と更新

論文・規格の結果には、適用した空間や測定条件がある。たとえば「残響時間が1.4秒」という値は、測定場所や周波数帯が分かって初めて設計に使える。具体的なワールドの設計値と、複数の場面に使える原理は、相互に参照できる位置に置く。試作で新しい事実が得られた場合は、影響する章の説明・図・条件を更新し、設計書や検証記録への参照を添える。

各ワールドの現行仕様、実装の入口と検証方法は、[探索ワールドの実装仕様](../worlds.md)、[アーキテクチャ](../architecture.md)、[検証と配布ビルド](../verification.md)を参照する。
