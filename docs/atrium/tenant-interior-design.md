## 配置の決め方

左の木の衣料店と黒い格子の衣料店、右の透明な小物売場が、正面通路から見たときの主な手がかりになります。回廊下では、間口の奥まり、柱、発光面、暗い入口を繰り返します。正面奥はソファ背後の展示島、枝状照明、黒い看板の売場と明るい区画が重なる構成です。通路から斜めに歩いたときにも、入口・手前の什器・奥の棚が個別に動いて見えるように配置します。

区画番号は添付の参照写真を手前から読んだ位置を示します。L1〜L5は左、R1〜R4は右、F1・F2は正面奥、I1〜I3は中央の展示ケースです。写真で直接確認できるのは開口の輪郭、手前の什器の一部、明暗と重なりです。入口の有効幅、店舗の奥行き、営業設備や奥壁の位置は仮想ワールド用の設計値です。L3〜L5、R3・R4、F1・F2の店内用途には設計補完を含みます。提供写真とその切り抜きは参照元として手元で管理します。図面のサインには仮の表示面を使います。

### 写真と設計寸法の照合

### 座標と基準高さ

- 世界座標は `x` が右、`y` が上、奥行き表示の `s=-z` が写真の奥方向です。共用部の仕上げ床を `y=0.000` m、間口面を `x=±11.40` m、階上の床レベルを `y=4.55` mとします。共用庇の光帯下端はおおむね `y=4.03` mです。
- 店内は `u` が間口に沿う位置、`d` が共用部から店内への距離です。左右の店は `s=span[0]+u`、`x=±(11.40+d)`。正面奥の店は `x=span[0]+u`、`s=plane+d` です。PDFとJSONはこの基準を共有します。平面の什器寸法は仕上がり外形で、通路幅は把手や棚の張り出しを含めた有効寸法です。
- 現行の側面外壁はおおむね `|x|=14.76` m付近です。奥行きがこれを越える店舗では、地上 `y=0.00〜4.03` mの該当区画の外壁を割り、側壁180 mm、奥壁200 mmで閉じた外形を作ります。西側 `x=-14.54` mの既存の化粧柱のうち、L1・L2の主通路に重なる地上部分はそれぞれ `s=11.69, 32.45` mの脇へ寄せます。階上の回廊下の柱・庇は既存位置へつなぎます。
- 正面奥の既存端部は中央にガラス、両脇に石壁、奥へ向かう袖壁を持ちます。F1は `x=-10.35〜-4.30` m、F2は `x=-1.16〜6.76` mの見通しに割り直します。手前の見切り面は `s=60.05` m、上端はF1で `y=3.62` m、F2で `y=3.68` mです。見通しの幅で床を `s=60.00` mから両区画の入口までFL±0でつなぎ、F1の西側にも床を通します。既存の `x≈±4.83` mの袖壁は、この二つの見通しと重なる地上部分を置き換えます。二つの区画の間に石の袖壁が残ります。奥店舗の外形は `s≤67.95` m（背面壁を含む）です。
- 入口前に段差を設けず、床の素材を敷居で切り替えます。ガラス枠の下レールと異種材見切りは床面とそろえ、共用床側に突出する上がり框を設けません。入店動線は将来の探索拡張に使える寸法です。共用部だけを歩く段階では、既存の共用部の支持面と店先の境界を使います。

### 売場と共用部の接点

L1とL2の間、R1とR2の間には、石目の艶を残した柱の見付けと縦型表示を置きます。柱型の面は通路に向け、テナント側の余った区間は間口の袖壁、サービス扉、奥まった反射面で処理します。m単位の区画間の余白を、同一の石の板面で一面に塞ぐと、写真の奥行きの刻みが消えます。柱の裏を暗くし、次の開口の光を袖で受けます。

地上の店先は基本の段差なしのルートでつなぎます。カフェ外席がある右は、階段脇からR2の引き込みへ向かう経路と屋外席の後ろの経路を分けて扱います。店舗の什器を共用床へ押し出して通過幅を確保する処理を避け、間口側で展示または扉を調整します。中央のケースは既存のソファの前に置かず、背後と左側に置きます。階段への通り道と座面からの主視線を残し、ケースの間を共用通路として連続させます。 [国土交通省の建築設計標準](https://www.mlit.go.jp/jutakukentiku/jutakukentiku_house_fr_000049.html)

## 区画別の設計

### L1 木の衣料店

写真の木の面で囲った大きな入口と、その手前の衣料ラックを残します。入口を抜けた先は季節衣料、畳み台、壁棚、奥の試着・会計の順です。最初に見えるラックは高さ1.40 m、畳み台は0.85 m。服の裾が下の台と重なり、奥の壁の上部も見える関係にします。奥右の会計台は幅1.65 m、奥行き0.62 mです。試着区画を正面からの主視線の横に寄せ、手前の待機ベンチと入口をつなぎます。

試着室は1室で、内法は約1.80 × 1.83 m、前面の有効開口は1.05 m、間仕切りは高さ2.55 mです。門型枠、奥壁、入口の袖をオーク練付けでそろえます。衣料は手前に柄物、次に白・桃・紺を配し、服ごとに肩・丈・裾の高さを変えます。入口枠の暖色ラインを2700 K、衣料を見る主光を3000 Kの系統に分けます。会計、試着区画と奥壁の割り付けはこの店の内装として補完しました。

### L2 黒枠の衣料店

正面は黒い縦框、黒い看板帯、乳白の上部光帯です。縦框の基準ピッチは約0.95 m。中央寄りの両引戸の奥に、左右の低い陳列台と衣料ラックを分けて置きます。服の間から、さらに後ろの横棚と黒い壁面が見えます。奥左に会計台、待機ベンチ、試着2区画を一続きに納めます。中央の幅1.50 mの主動線は入口から奥の黒い壁まで通します。

試着室の内法は約1.55 × 2.20 mと約1.89 × 2.20 mで、いずれも開口1.05 m、仕切り高さ2.55 mです。黒ブロンズと暗い木天板の輪郭を抑えた艶で仕上げます。白い陳列台を手前に、黒い棚を奥に置き、乳白帯と衣料を見る光を分けます。上部帯の発光と室内の棚灯が正面ガラスの同じ位置に重なると、黒枠が消えるため、器具の向きは店内側へ寄せます。写真に見える白い台座の範囲には、服の台、ラック、平置きを分けて展示の密度を作ります。

### L3 奥まった入口の店

濃い入口枠の右側に明るい袖壁が見える構成を使い、入口を1.05 m引き込みます。入口直後は有効幅1.30 mの視線と通路を空け、低いケースを両袖の奥へ置きます。前のケース、淡色木の側面棚、奥の会計と左官壁の順に見え方を変えます。商品は革小物、バッグ、箱物を使う設計補完です。入口の光は袖壁と門の内側に向け、商品面には別の小さなスポットを当てます。

### L4 金色の縦目の店

写真の金色に見える縦面を、透明ガラスの内側のシャンパン色金属リブとして設計します。見付け20 mm、基準ピッチ180 mm、ガラス面から前へ出す見込みは30 mm以内。リブは上下の見切りで支持し、奥壁の縦模様と位置が少しずれるようにします。手前の小ケース、中程の側面棚、奥の会計を低めに構成します。内部で見える商品はアクセサリーや小箱としました。縦目の細い反射が強く出る一方、天板上の商品には落ち着いた面の光を残します。

### L5 左奥の小間口

小さな発光面と暗色の細枠を入口の目印にします。1.45 mの有効幅を取り、戸は二枚連動片引きで袖側に重ねます。小さなケースと浅棚は左右に寄せ、中央の1.20 mを会計前まで通します。ケースの下端に100 mm程度の台輪を設けて床際を閉じ、奥壁は低い棚面を重ねます。ギフト・生活小物という用途と奥の棚配置は設計補完です。

### R1 全面ガラスの小物売場

写真右端の長いガラス間口を、ガラス外皮、吊りガラス片、縦光の群、陳列の四層に分けます。入口は撮影範囲の外側となる手前端 `s=13.30〜15.50 m`（`u=1.50〜3.70 m`）に寄せ、写真で見えている側に連続したガラスの展示面を残します。入ると、手前の高さ0.78 mの低卓、中程のショーケースと棚、奥の高さ2.35 m前後の照明棚へ視線が進みます。天板には白と淡色のトレー、その上に高さと色を変えた小瓶と小箱を分けて置きます。香水・化粧品は瓶の形から採った設計上の想定です。

ガラス棚と淡い塗装・石目の低卓を細い金属枠で支え、前面ガラスの目地と什器の見切りの位置をずらします。短い透明片は天井側に集め、縦光は床際近くまで落ちる細い束を間隔と長さを変えて配置します。光の束は通路と什器の間を避け、低卓と壁棚は上から別の配光で照らします。写真の右手前らしさは、通路に立ったときに束の向こうに物が見え、さらに床に線だけが離れて映ることにあります。

### R2 植栽のあるカフェ間口

植栽の横帯、大鉢、共用部の椅子、石柱で分かれた間口を写真から確認した。現在は入口4.20 mと間口10.10 mを維持し、奥行きを18.40 mへ拡張する。詳細な26席・サービス・支持・照明・6基のスピーカーの仕様は[大型カフェの設計](cafe-interior-design.md)を正本とする。画像外の店内は独自設計であり、写真の実施設寸法の復元ではない。

### R3 明るいガラス間口

石柱の間に見える透明な間口を、明色の小物・ギフトの売場として補完します。入口は `u=3.85〜5.55 m` の固定ガラスの間に置き、左側に戸を引き込みます。左右の低いケースの先で有効1.35 mの通路を曲げ、奥の棚面を再び正面に見せます。ガラスの続きに明色の壁と細い金属縁を置き、面の光が什器から奥壁へ段階的に続くようにします。照明はガラスを正面から狙う位置を避けて、ケース天板と奥棚の前縁へ向けます。

### R4 階段脇の暗い小間口

階段脇から見える青灰色の帯、低い軒、暗い側壁を手がかりにします。幅2.70 mの内側は、薄いケースと浅棚を両側に寄せ、中央1.20 mを奥まで通します。入口には1.40 mの有効幅を取り、横に広がる島台は置きません。階段側は濃色のマットパネル、展示側は低反射のガラスと淡い棚板にして、小さな店内の光が階段の手すりを白く巻き込まないようにします。小物の短時間立ち寄りを想定した設計補完です。

### F1 正面奥の暗色区画

奥の設計データの `u` は写真左から右、`d` は各店舗の間口面から奥へ向かうローカル寸法（m）である。F1の `plane=61.90` は間口面、depth 5.85mの後壁は世界 `s=67.75` に置く。写真の黒い看板と暗部を、黒色細枠のガラス間口、黒褐色マイクロセメントの後壁、暖色の縁取り照明で構成する。

入口は `u=3.55–4.95`、主歩行軸は `u=4.25` とし、`d=0.0–5.2` を直線で通す。開口上部は高さ150mmの無地黒枠とし、表示面を設けず、2700Kの乳白拡散光で入口を認識させる。天井は設計天井高3.10 mとし、黒色の細いリニア見切りを後壁へ通す。

左側に高さ1.05mの低い黒色ケースと高さ2.10mの暗色壁面棚、右柱際に幅380mm・高さ1.25mの縦長ガラスケースを置く。後壁左寄りのサービス台は高さ0.92m、浮かし壁は高さ2.35mとし、主通路1.20mの帯域から外す。後壁は腰から1.8mまで防汚クリア、上部は艶を抑え、2700Kのウォールウォッシャーで水平に均す。ケース内部は2700–3000K、棚背面は2700Kの縦ラインとする。

ワールドの立位視線1.65 mと着座視線1.20mをF1の確認基準にする。低層ケースの上端を1.25m以下に抑え、入口から後壁の暗い面まで視線を通す。仮想空間には人、マネキン、固有名、ロゴを配置しない。

### F2 枝越しに見える明るい区画

F2の `plane=62.20` は間口面、depth 5.50mの後壁は世界 `s=67.70` に置く。入口は `u=2.80–5.20`、開口2.40m、主歩行軸 `u=4.00`、主通路1.40m、`d=0.0–4.8` とする。右端の固定ガラスは床から天井まで透明面で連続させ、写真に写る階段の斜めガラス手すりと明るい後壁の見通しを保つ。

天井高3.25mを活かし、天井際に2700Kの連続コーブ照明を納める。後壁はアイボリーの微細テクスチャと乳白の面発光、境界は明色の細い見切り1本とする。中央に強い点光源を置かず、面発光と低層ケースの反射で写真の高照度感を作る。右壁際の幅500mmの縦光スリットは3000K・低輝度とし、手すりの反射線を保持する。

## 音響

共用部には現行の換気3点、設備2点と、視点に追従する足音の系統があります。床、壁、軒裏の位置から初期反射を求め、後期残響の設計値は吹き抜け1.86秒、軒下側0.95秒です。新しい売場は既存の設備音に接続し、仕上げと開口で聞こえ方に差を付けます。 [現行の音響仕様](../worlds.md#商業アトリウム) · [商業施設の残響実測研究](https://www.mdpi.com/2076-3417/10/3/1170)

- **R2の開口。** 機器音は[カフェ共通Plan](../../src/coast/world/atrium/atriumCafePlan.ts)の `ATRIUM_CAFE_EQUIPMENT_POSITION`（local `u=.60,d=5.80,y=.65`、世界 `x=17.20,y=.65,z=−34.05`）を使う。サービス背面下台の冷蔵・洗浄側に置き、開口を通る経路と閉鎖備品室の遮蔽を同じ区画定義から求める。機器の可視位置・音源・共有スピーカーの最終統合を別々の座標で管理しない。
- **閉じたガラスの区画。** 発音点と耳を結ぶ経路が固定ガラスや閉鎖戸を横切るときは直接音と高域を弱め、開口を通る経路には開放側の設定を使います。ガラスを通った音と通路側の反射は角度で分けます。音源の追加・位置変更を伴う実装では、既存の距離・遮蔽・反射の計算と `service` バスへ接続します。
- **床材。** 共用石材は明瞭な短い音、中央の敷物は立ち上がりの柔らかい音です。入店動線を開放する段階では、木の衣料店とカフェの床を別の面として判定し、敷居を越えた足音の硬さと残響の聞こえ方を確認します。

ソファ、左の木の売場の前、右手前のガラスの前、カフェ横の開口、中央展示島の順に移動し、定位とガラス越しの高域の違いを確認します。残響時間と音量の出発点は仮想ワールドのパラメータです。 [現行の反射と遮蔽の実装](../../src/coast/world/atrium/atriumAcoustics.ts)

## 3D制作への引き継ぎ

### 制作単位

1. **間口と囲い。** [座標データ](tenant-interiors.json)の開口、引き込み、天井を先に立てます。左右の浅い展示区画を新しい囲いへ差し替え、既存の外周壁と化粧柱が通路を横断するところを処理します。F1・F2は既存の背面壁と袖壁を矩形の見通しに割り直し、背面奥まで床と天井をつなぎます。共用部の探索境界 `s=60.00` m は、地上の入口面とは独立に参照します。
2. **前景・中景・奥。** 什器IDごとに床面を原点とし、`rect` の幅と奥行き、`height` を制作寸法に使います。台上の商品・衣服の形や吊り物は別メッシュで置き、描画用のバッチにまとめます。高さを持つ什器の衝突面は主要寸法と合う箱または円弧で作ります。ガラス面、内側の什器、背景の棚を別レイヤーとして照合します。
3. **仕上げと光。** 木目、石目、ガラスや金属の見え方を色・法線・粗さの要素で調整します。陳列正面の光と什器内部の発光部分を別に設定します。全消灯で発光部と照明の効果が一緒に落ち、天窓と共用部の昼夜が変わっても店内の明暗が同じ順で読めるようにします。
4. **視差と反射。** 透明面一枚の外側に複数の透過層を重ねる箇所を抑えます。ガラスの縁、薄い棚、金属の輪郭は斜め移動で位置がずれ、床の映り込みは店の発光位置に対応します。PCの通常画面の床反射と、WebXRで各眼から求める既存の床反射に店先の光の位置を渡します。 [glTFの材質モデル](https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html#metallic-roughness-material) · [現行の床描画](../../src/coast/world/atrium/atriumFloor.ts)

## 図面の更新と再生成

各区画の間口面、入口、主通路、什器を直すときは [座標データ](tenant-interiors.json) を更新し、続いて該当する区画の文章と図面を更新します。JSONの `span`、`plane`、`depth`、`entry`、`route`、`fixtures` は仕上がり寸法を m で記録しています。投影表の元画像上の列は、見えている側の端だけを画素で記録します。図面はA3横で、図ごとの縮尺と縮尺棒を記載しています。

ReportLab を利用できる Python 3.10 以降で、リポジトリ直下から生成します。入力はリポジトリ内のJSONです。寸法検査は標準ライブラリで実行できます。

```bash
python3 scripts/check-atrium-tenant-interiors.py docs/atrium/tenant-interiors.json
python3 scripts/draw-atrium-tenant-interiors.py --invariant docs/atrium/tenant-interiors.json docs/atrium/tenant-interior-drawings.pdf
npm run validate:harness
```

PDFはA3で出力して図の縮尺棒を確認します。更新した頁は原寸で、全体はページ画像でも確認します。室内動線は入口と主な目的位置の間を指定幅で検図します。図面・設計値の整合確認は、施工図の構造計算や作成後の画質・音の検証とは確認時点が異なります。
