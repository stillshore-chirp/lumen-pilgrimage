# 光庭とコモンズの植栽設計

本稿は2026-11-27の専門設計と改訂設計査読を踏まえた植栽仕様であり、現行の葉実装と局所検証を併記する。現行の利用方法は[ワールド仕様](../worlds.md#商業アトリウム)、実装と検証の経緯は[Issue #269](https://github.com/stillshore-chirp/lumen-pilgrimage/issues/269)を参照する。建築・共通寸法の正本は[施設設計](sofa-facing-facility-design.md)。局所幾何の成功と、最終実アプリの目視受入は分けて扱う。

設計基準はbase `31a37ae`。植栽の実装は[`atriumFrontGarden.ts`](../../src/coast/world/atrium/atriumFrontGarden.ts)、配置入力は[`ATRIUM_FRONT_GARDEN`](../../src/coast/world/atrium/atriumFrontPlan.ts)を参照する。建築主任と共有した座標はm、FL±0を共通基準とする。方位・呼称は **W＝−X＝ソファから+Zへ向いた着座右、E＝+X＝着座左** に固定する。以下の東西はこの座標系を指し、図面上の左右と混用しない。

## 1. 判断と役割

ソファ `[-2.7,1.2,-29.7]` から+Zを見る改修前の景観は、正面の平板壁と上下階の同形パネルが重なり、床の先に滞在先や用途を読み取りにくかった。確認した原画のz0から-Zの商業アトリウム景観には、建築の大きな重なりと、小さな生きた植物の細部という階層がある。新設部分でもその階層を用いる。

**採用案は、ガラスの奥に片寄せた1本の細葉樹と低い葉群を置く「光庭」。左右・上階に鉢は並べない。** 植物は建築の用途や奥行きに添えるもので、殺風景な大壁を植物だけで隠す役割は持たせない。主木の樹冠幅1.5mはソファから角幅約2.2度にすぎない。遠景の改善は、主任の奥壁受光面・見込み厚・上階コモンズが担う。緑は近づいたとき、幹、葉序、根元、管理された地際を発見できる役割を持つ。これは設計所見であり、利用者の静けさや回復効果を実測した結論ではない。

候補比較:

| 案 | 判断 | 利用への影響 |
| --- | --- | --- |
| 鉢を左右へ等間隔配置 | 不採用 | 未用途パネルの反復をさらに強め、通路と商品視界を狭める |
| 高さ4m超の大木・多樹種の密林 | 不採用 | 天井約4.1mと不整合。庭の奥壁・幹・床の層を隠す |
| 植栽なし、素材と光のみ | 条件付き代案 | 維持・光源の成立性が確保できない場合に選ぶ。光庭の床と受光壁は維持し、偽の樹冠で穴埋めしない |
| 細葉樹1本＋ハランの3つの偏在群 | 採用 | 視線軸を開け、木の枝と低い葉の異なる尺度を作る |

現行実装は前群16株・奥群17株・西奥7株の計40株を、固定seedで非等間隔に配置する。1株5〜7葉、全体238葉。三つの群を同形・同株数にせず、土と樹冠下の空白を残す。葉改訂ではこの株数・葉数・株心と葉柄の接続位置を維持した。

根鉢セルは主木下 `x[.35,1.65], z[7.85,9.15], y[-.35,.30]` に、基盤内から床下へつながる深さ.65m、約1.10m³の局所槽を仮定する。+.35mだけの浅い土に高さ約3mの樹木を刺さない。これは建築主任が採用可能と判断した設計仮定であり、苗木の規格や実施設の配管・地盤・構造から確定した値ではない。実施設では根鉢寸法・排水・床耐力・防水を確認して確定する。

描画は地表・根張り・葉柄基部までを扱い、土中の根系や排水動作を再現したものではない。根鉢セルの容積は実施設を考えるための設計仮定であり、実際の生育を検証した証拠には含めない。

## 3. 一次資料と樹種の採用条件

### 主木: 細葉フィカス、園芸流通名 ‘Alii’

Kwantlen Polytechnic Universityの教育用植物DBは、‘Alii’を室内向け・鉢栽の成熟高2〜3m、幅1〜1.5mとし、互生する線形の全縁葉を15〜20×2〜3cmとしている。この寸法を樹体と一枚ずつの葉に反映する。**FL3.25mは、土面約+.30m＋樹体約2.95mの合計。** [KPU Plant DB・sabre fig](https://plantdatabase.kpu.ca/Plant/fibn)

資料では `Ficus binnendijkii 'Alii'` の園芸名を使う。細葉の室内フィカスには植物学上の同定の揺れがあるため、本設計では園芸名と資料に記載された葉形を採用し、野外の最大樹高を室内の寸法根拠に混用しない。園芸流通個体の葉の二形性については、Bergen Museum等所属のBergによる原著も確認した。図版は使わない。 [Berg 2007・葉の二形性と室内流通個体](https://li01.tci-thaijo.org/index.php/ThaiForestBulletin/article/download/24194/20575)

UF/IFASの室内フィカス技術資料では、光条件の急変を避けた順化、通気と保水の両立した用土、剪定による内部採光の維持が必要とされる。低照度で維持できた報告は、順化した生産個体等の条件付きであり、暗い庭でも無条件に生育する根拠にしない。主木は枝が透ける管理樹形とし、光源のない暗い箱には置かない。 [UF/IFAS ENH879・pp.1–2「Production」「Shipping and Interior Care」](https://ask.ifas.ufl.edu/publication/EP136/pdf)

### 低植栽: ハラン `Aspidistra elatior`、斑なしの濃緑

NC Stateは、ハランを地下茎で広がる耐陰性の多年草とし、排水性のよい土、地際から直接出る葉、長い葉柄、平行脈のある革質葉を記載する。小さな木の枝に葉を付ける造形にはしない。白斑や斑点品種、花は使わず、主木の細い葉との尺度差をつくる。全高は個体差があるため、上表の高さを苗の選別・配置条件とする。 [NC State Extension・Aspidistra elatior、Description/Leaves](https://plants.ces.ncsu.edu/plants/aspidistra-elatior/)

## 4. 現行の形状・地際・素材

- 主木は根元径.105mの単幹を曲線に沿って先端へ細くし、6本の根張りを土へつなぐ。8本の主枝と40本の細枝は異なる高さ・方向から出る。主枝の開始点は幹曲線上の同じ高さから求め、根元を推測座標で離さない。編み幹や巨大な気根は使わない。
- Aliiは368葉。各節に互生する長さ.15〜.20m・幅.02〜.03mの葉を、横断3列・長手7分割で作る。長手に沿うねじれと先端の下垂を連続化し、葉柄・幹・枝と枚数は葉改訂の前後で維持した。樹冠を球や交差板へ置換せず、葉裏と薄い側端を含めて閉じる。
- ハランは40株238葉。横断5列・長手11分割で浅い椀形と主脈の1〜2mm程度の稜線を作る。既存の葉柄先端を起点に、成熟葉は上部で開いて先が下がる、中間葉は半直立、少数の若葉は幅を狭めて浅く巻く。形態割当ての設計比率は成熟55%・中間30%・若葉15%で、葉数と接続位置を変えず固定seedから決める。全縁を保ち、輪郭に乱数ノイズを足さない。
- 葉脈は種別の手続き法線で扱う。ハランは平行脈、Aliiは細い羽状脈で、同じ模様を両種へ流用しない。各128×128のDataTextureを生成し、色空間変換のないnormalMapとして使う。外部写真・図版・既存の樹冠atlasは使わない。
- 表は濃緑、裏は少し彩度を下げた灰緑。PBR roughnessはAliiの表.61／裏.81、ハランの表.59／裏.81とする。これらは描画パラメータであり、実葉の粗さの測定値ではない。種ごとの全葉を表・裏の2つのindex群へまとめ、葉1枚ごとに材質やdrawを増やさない。両種とも非発光で、閉じた薄い葉厚はAlii約.4mm、ハラン約.9mm。
- 基盤の見付けは既存と同系の淡い温灰色石材、天端幅50mm、FL0から+.35mの連続した石縁。土面は+.30mで縁より50mm下げる。細かな暗褐色バーク片を土面上約3〜16mmに置き、幹周囲半径.23m内には片の中心を置かず根元を見せる。根張りは土面へ、葉柄基部は土面下約6mmまで重ねる。白い玉石の一面敷きや、深緑の一枚板で地表を隠さない。
- 植物の根鉢と水管理は群ごとに分けられる連続基盤を前提にする。床は基盤の手前から奥壁まで同じ高さで連続させ、基盤の接地影と土の高さを見せる。ガラス手前の鏡面床は維持し、庭の床だけは同系色のやや粗い仕上げで反射を弱くする。

葉改訂後のCPU外包は、Aliiの冠幅がX約1.407m・Z約1.421m、最大水平半径約.74881m、最上葉FL約3.211m。許容冠幅1.35〜1.50m・最大上端3.40mの内側にある。これは生成形状の寸法照合であり、実画像で葉の量感や樹形を受け入れた結果とは分ける。

観賞G2は葉を奥壁より一段低い中間調に置く。G4を強めて鑑賞の露出を合わせる処理は採らない。緑の自発光、全球Ambientや全体露出の変更を使わず、器具位置と遮蔽物に対応する局所の受光を作る。G1奥壁ウォッシュは主木より奥の光源であり、奥壁の枝影を必須にしない。枝が実際に光路を遮る光源・枝の組合せがある部分だけに影を生じさせる。

G2の静的影、影用視錐台、品質別map、dirty時の更新、全消灯・PC/XR・床反射との整合は[照明・素材設計](sofa-facing-light-material-design.md)の責務とする。植物側は実形状のcast/receiveShadowを提供する。光の円錐と影カメラの正方形視錐台は異なり、影生成を植物だけに厳密限定したとは扱わない。G2の外側にある前群全域へ影が出るとも保証しない。間接光に残る接触AOと、G2消灯で消える直達影を分けて確認する。

現行の植栽材と土材には接触AOを設定していない。内装の接触AOは建築shellと内装groupへ適用され、庭の植物・土床groupは対象外である。土はroughness1・receiveShadow=trueのPBR材で、根張り・葉柄の実接続とG2の直達影を扱う。間接光で均一に見える土面を、植物用AOが実装・達成された証拠にはしない。

生育は本VRで保証しない。UF/IFAS本文p.2には、低光量へ順化した個体等の条件とともに室内100〜200fc、‘Alii’には50fcでも使用し得る旨がある。50fcは約538lx、100〜200fcは約1076〜2153lxという**条件付きの資料値**であり、本案の普遍的必要量・最適量・採用照度ではない。生産遮光条件の異なる9品種を室内50/100fcで1年間評価した記述もあり、個体の順化を照度から切り離せない。fc/lxは視感度に基づく照度なので、その数値だけで植物への有効光量や日積算光量を満たすとはしない。実施設化では専門業者が実測してG4の光量と日次運転を確定する。温度約18〜27℃、空調の直風が主木に当たらない環境を前提とする。 [UF/IFAS ENH879・本文p.2](https://ask.ifas.ufl.edu/publication/EP136/pdf)

用土は清潔で通気・排水性のある市販の室内植物用培地を使う想定。UF/IFAS記載の樹皮・ピート・パーライト等の機能を参考にするが、配合比を実測なしに固定しない。槽には防水・防根、排水口、点検可能な排水受けを設け、根鉢を滞水へ浸さない。東側管理帯の奥へ目立たない点検蓋を置く。鉢を大きくすればよいという発想は採らない。過大な容器の長期湿潤リスクと排水穴の必要性は大学・植物園の一般指針にもある。 [Illinois Extension・Container/Potting Mixes](https://extension.illinois.edu/houseplants/get-started) · [NYBG・Repotting](https://libguides.nybg.org/houseplantcare)

W＝−X＝着座右の装丁・文具店、E＝+X＝着座左の生活工芸店と上階コモンズには追加植栽を置かない。新店舗の共通座標は `u=z+10.2, d=|x|−11.4`、背景棚はW側`d4.25`、E側`d4.65`で主任の最新版へ一致させる。用途を示す家具・棚・カウンターと陰影の深さを優先する。主通路の幅を植物で消費せず、利用者が立つ・座る場所から光庭へ視線が通る。人形・通行人・新しい水景は加えない。葉や水音による静けさの演出も追加しない。
