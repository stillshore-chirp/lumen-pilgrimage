# 商業アトリウム正面改修・音響設計

本稿は2026-11-27に実装前の独立設計査読を終えた専門設計の記録である。後述の未実施項目は設計時点の確認境界を示す。現行の実装・利用方法は[ワールド仕様](../worlds.md#商業アトリウム)、実装と検証の経緯は[Issue #269](https://github.com/stillshore-chirp/lumen-pilgrimage/issues/269)を参照する。建築・共通寸法の正本は[施設設計](sofa-facing-facility-design.md)。

## 対象と結論

base `31a37ae`。設計・一次資料調査のみ。ソース、Git、GitHubは変更していない。用途は、人のいない私有施設のソファで静かに留まり、歩くと空間の奥行きと材質が分かること。庭・売場・展示に新音源を置かず、既存の空調3点、設備2点、自分の足音を維持する。建築変更には正面固定ガラスの有限反射面を対応させる。

原画と概観では硬質床、布張りソファ、吹抜け、庇が確認できる。原画の人の活動音は今回の用途へ持ち込まない。光庭の植栽を風音・鳥声・水音の理由にせず、水景・環境音楽・店舗チャイムも追加しない。豊かさは音源数より、見える面と返ってくる音の整合で作る。

## 実読した一次資料と適用

## 共有座標と聴く順序

単位m、Y上。座面 `R=(-2.7,1.20,-29.7)`、yaw=π、概ねforward `+Z`。この向きでは**負Xが右、正Xが左**。頭の回転だけで音源を回転させない。

| 距離層 | 聴くもの・役割 |
| --- | --- |
| 近景 | 静止中は発音しない。立ってラグを離れると、柔らかい接地音から石床の音へ変わる。布や葉に常時ループを足さない。 |
| 中景 | 既存空調A0 `(-9.70,3.93,-13.50)` は右前17.86m、A1 `(9.60,3.93,-40.90)` は左後16.86m。小さな稼働感を担う。 |
| 遠景 | A2 `(-9.90,12.93,-44.50)` と既存設備は床・店舗の遮蔽を受ける。長い吹抜け尾部が広がりを担う。光庭は正面32.74m先の静かな視覚終端。 |

## 実装へ渡す仕様

`atriumLayout.ts`相当の共有定義に完成面を置き、描画と`atriumAcoustics.ts`から参照する。現行`considerReflection`へ`front-glass`候補を加える。音源と耳がアトリウム側にあり、鏡像線の交点が各有限面内にある時だけ採用。Z>3を一律に捨てる現在のクリップは、この面だけ共有Z=3.04まで許可する。歩行boundsは広げない。4面を同じ処理で扱い、候補は表の面内に限定する。上階3ベイの支持枠を含む硬質前面を一面へまとめる場合は、その形状近似を記録する。

| 項目 | 仕様・理由 |
| --- | --- |
| 新面係数 | `.30`を調整開始値とする。既存側壁`.33`に近い相対ゲインで、ガラスの測定反射率・吸音率ではない。既存距離/遮蔽フィルターを使用。 |
| 初期反射 | 強い2経路、音速343m/s、超過遅延上限180msを維持。新面のために声数を増やさない。 |
| 残響 | `void:1.86 / sheltered:.95`、開始29/16msを維持。既存の手続合成尾部の包絡パラメータで、現施設の帯域別RT実測値ではない。 |
| 音源・音量 | 空調baseGain `.23/.22/.20`、設備`.17/.16`、夜の設備倍率`.64`を維持。air帯域82–1050Hz、service45–420Hz/67Hz成分、master基準`.602`も据置。 |
| 更新 | 頭向きは既存毎フレーム更新。経路更新75ms・移動閾値2cm、ゲイン/フィルター平滑化も維持。 |

ガラスの後方へ音源・聴取者を置かないため、新たな透過/開口モデルは不要。植栽に遮音値を与えず、ラグ・ソファ近傍の短い尾部、床/庇・既存店舗開口/遮蔽を継続する。新規録音・RIR・特許方式は採用せず、現行経路候補を共有形状へ接続する範囲に限定する。

## 計算確認と受入条件

以下は幾何計算・現コードの読取結果で、録音や実機聴取の結果ではない。

1. `R=(-2.7,1.65,1.2)`、試験短音源`S=(-2.7,.045,1.2)`の場合、正面交点`(-2.7,.8475,3.04)`、直接1.605m、反射4.0148m、超過7.026ms。新面が選ばれた場合、経路計算の`reflection.delay`がこの値と誤差1サンプル以内で合うこと。録音波形にはフィルター等の遅延も加わる。有限面外の交点は不採用とする。
2. 座面と同Zの試験足音では正面反射の超過187.566ms。180ms上限で除外されること。静けさを損ねるため上限を伸ばさない。
3. 現コード計算で座面localTailMix=.369857。新面追加で尾部・音源数・既存直接経路を変更しない。方位だけ180°回した時も距離/遮蔽は同じで、Listenerの向きだけ変わること。
4. 同じヘッドホン/音量/時刻で、座面→石床→正面ガラス前→側廊→ソファの30秒録音と頭の±90°回転を保存。静止時の足音ゼロ、方向の世界固定、ガラス接近時の短い返り、クリック/急な音量変化なしを確認する。快適さは専門所見と利用者評価を分ける。
5. 変更後は`npm run check`、ビルド後`npm run test:coast:browser`と既存`test:atrium:browser`。新面の遅延/有限面判定は`atrium-audio.test.mjs`へ追加する。長短IRは既存のT20回帰範囲検査を利用し、新たな帯域別RT達成は主張しない。

## 証拠・未実施・残リスク

確認済み: 共通/作業ツリーAGENTS、harness、規約、文書責務、`atriumAudio.ts`/`atriumAcoustics.ts`/`atriumAudioSamples.ts`/`atriumLayout.ts`、既存音響試験、専門書音環境章。Nodeで既存座面経路を計算し、Pythonで上記2経路を再計算した。変更ファイルは本書だけ。

未実施: 実装、ブラウザ録音、ヘッドホン聴取、帯域別IR測定、再生系校正、利用者評価。dBFSをdB SPLへ換算していない。2経路＋2尾部は角回折・曲面散乱・実材料周波数特性・隣室再流入を解かない。ガラスの新面追加は局所の整合改善であり、物理的に正確な施設音響の達成を意味しない。
