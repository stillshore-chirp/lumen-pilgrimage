# 商業アトリウム正面改修・音響設計

本稿は2026-11-27に独立設計査読を終えた音響設計と、その実装・局所回帰の確認境界を定める。庭両側の資料展示室を加えた14区間の固定窓組立を対象とする。利用方法は[ワールド仕様](../worlds.md#商業アトリウム)、実装と検証の経緯は[Issue #269](https://github.com/stillshore-chirp/lumen-pilgrimage/issues/269)を参照する。建築・共通寸法の正本は[施設設計](sofa-facing-facility-design.md)。

## 対象と結論

初期設計の基準は `31a37ae`。用途は、人のいない私有施設のソファで静かに留まり、歩くと空間の奥行きと材質が分かること。庭・売場・展示に新音源を置かず、既存の空調3点、設備2点、自分の足音を維持する。建築変更には正面固定窓組立の有限反射面を対応させ、共有Planと音響実装を同じ完成面へ接続している。

原画と概観では硬質床、布張りソファ、吹抜け、庇が確認できる。原画の人の活動音は今回の用途へ持ち込まない。光庭の植栽を風音・鳥声・水音の理由にせず、水景・環境音楽・店舗チャイムも追加しない。豊かさは音源数より、見える面と返ってくる音の整合で作る。

## 実読した一次資料と適用

| 資料・実読箇所 | 採用する知見／適用限界 |
| --- | --- |
| [Alnuman & Altaweel, 2020](https://www.mdpi.com/2076-3417/10/3/1170)、§2.2、§3、§4 | 空室RTと占有中騒音を分け、頭高・反射面との距離・帯域・雑音床を記録する。実モールの群衆音量や消防放送のRT目標を、私有VR施設の快適値へ転用しない。 |
| [Allen & Berkley, 1979、著者公開原著](https://jontalle.web.engr.illinois.edu/Public/Allen-PDFs/PDFs/AllenBerkley79.pdf)、pp.943–946、§I.A–B、§II | 鏡像距離で反射到来を計算する一般原理。原著は主に矩形小室で、非剛壁も近似。曲面階段・吹抜け・回折まで正確に解ける根拠にはしない。コード・図・データは転用しない。 |
| [W3C Web Audio Recommendation, 2021](https://www.w3.org/TR/2021/REC-webaudio-20210617/)、§1.11、§1.27、§6 | Listenerの位置・forward/upとHRTF定位を維持。HRTFのステレオ出力は個人の耳を校正した結果ではなく、全利用者の前後定位を保証しない。 |

## 共有座標と聴く順序

単位m、Y上。座面 `R=(-2.7,1.20,-29.7)`、yaw=π、概ねforward `+Z`。この向きでは**負Xが右、正Xが左**。頭の回転だけで音源を回転させない。

| 距離層 | 聴くもの・役割 |
| --- | --- |
| 近景 | 静止中は発音しない。立ってラグを離れると、柔らかい接地音から石床の音へ変わる。布や葉に常時ループを足さない。 |
| 中景 | 既存空調A0 `(-9.70,3.93,-13.50)` は右前17.86m、A1 `(9.60,3.93,-40.90)` は左後16.86m。小さな稼働感を担う。 |
| 遠景 | A2 `(-9.90,12.93,-44.50)` と既存設備は床・店舗の遮蔽を受ける。長い吹抜け尾部が広がりを担う。光庭は正面32.74m先の静かな視覚終端。 |

閉鎖面は以下の計14区間。共有定義は [ATRIUM_FRONT_GLASS_PLANES / ATRIUM_FRONT_GLAZING](../../src/coast/world/atrium/atriumFrontPlan.ts)。完成面Z=3.040は歩行上限Z=3の0.040m外で、描画する14mm板は+Zへ置き、裏面Z=3.054・芯Z=3.047となる。反射には板芯を使わない。庭・展示室の床・壁・天井は固定窓の背後で閉じ、通行開口はない。

| 有限反射面 | 区間数 | X範囲 | Y範囲 | 完成面Z |
| --- | --- | --- | --- | --- |
| 1F光庭 | 1 | [−4.48, 4.48] | [.12, 3.92] | 3.040 |
| 1F西・装丁と紙の資料展示 | 2 | [−10.80, −9.13] / [−8.85, −5.40] | [.15, 3.35] | 3.040 |
| 1F東・器と木工の資料展示 | 2 | [5.40, 8.85] / [9.13, 10.80] | [.15, 3.35] | 3.040 |
| 2F展示・読書前面 | 3 | [−8.85, −4.86] / [−4.58, 4.58] / [4.86, 8.85] | [4.70, 8.07] | 3.040 |
| 3F前面 | 3 | 同上の3区間 | [9.30, 12.67] | 3.040 |
| 4F前面 | 3 | 同上の3区間 | [13.70, 16.55] | 3.040 |
| 合計 | 14 | 主要支持柱・室間の隙間を除外 | 各組立の上下内法に限定 | 3.040 |

各区間は透明な玻璃だけでなく、同じ完成面に納まる金属框を含む名目上の固定窓組立を代表する。描画では透明板を実際の框内法へ分割するが、音響側で細い金属框を無反射の穴にはしない。主要支持柱は別扱いで、1Fのx±8.99・幅.28m、上階のベイ間x±4.72・幅.28mを反射区間から除く。これは窓組立を一つの有限面とする近似であり、玻璃と金属の周波数別反射特性が同じという主張ではない。

## 実装仕様

[atriumAcoustics.ts](../../src/coast/world/atrium/atriumAcoustics.ts) の`inFrontGlass`は共有Planの14区間を参照する。`considerReflection`の`front-glass`候補は、音源と耳がアトリウム側にあり、鏡像線の交点が区間内にある時だけ採用する。区間は同一平面なので、その和を一度だけ判定して重複到来を防ぐ。Z>3のクリップはこの有限面に限って完成面Z=3.040まで許可し、床・側壁など他面の上限と歩行boundsは広げない。

| 項目 | 仕様・理由 |
| --- | --- |
| 新面係数 | `.30`を調整開始値とする。既存側壁`.33`に近い相対ゲインで、ガラスの測定反射率・吸音率ではない。既存距離/遮蔽フィルターを使用。 |
| 初期反射 | 強い2経路、音速343m/s、超過遅延上限180msを維持。新面のために声数を増やさない。 |
| 残響 | `void:1.86 / sheltered:.95`、開始29/16msを維持。既存の手続合成尾部の包絡パラメータで、現施設の帯域別RT実測値ではない。 |
| 音源・音量 | 空調baseGain `.23/.22/.20`、設備`.17/.16`、夜の設備倍率`.64`を維持。air帯域82–1050Hz、service45–420Hz/67Hz成分、master基準`.602`も据置。 |
| 更新 | 頭向きは既存毎フレーム更新。経路更新75ms・移動閾値2cm、ゲイン/フィルター平滑化も維持。 |

固定窓の後方へ音源・聴取者を置かないため、新たな透過/開口モデルは不要。植栽に遮音値を与えず、ラグ・ソファ近傍の短い尾部、床/庇・既存店舗開口/遮蔽を継続する。音源と生成信号は [atriumAudio.ts](../../src/coast/world/atrium/atriumAudio.ts) / [atriumAudioSamples.ts](../../src/coast/world/atrium/atriumAudioSamples.ts) の既存実装を維持する。新規録音・RIR・特許方式は採用せず、現行経路候補を共有形状へ接続する範囲に限定する。

## 計算確認と受入条件

以下の幾何計算と有限面判定は [atrium-audio.test.mjs](../../scripts/atrium-audio.test.mjs) に実装し、`npm run test:atrium`で局所確認した。試験の短音源は経路を検証する入力で、施設に追加する音源ではない。`reflection.delay`は直接経路に対する超過遅延を表し、録音波形にはフィルター等の遅延も加わる。

| 共有形状・保持する契約 | 局所回帰で照合する結果 |
| --- | --- |
| 光庭と上階の既存10区間 | `R=(-2.7,1.65,1.2)`、`S=(-2.7,.045,1.2)`で交点`(-2.7,.8475,3.040)`、直接1.605m、反射4.0148m、超過7.026ms。各階・各ベイで同じ相対高さの経路を確認する。 |
| 1F資料展示の追加4区間 | 各区間中心xで`R=(x,1.65,2)`、`S=(x,.045,2)`とし、交点y=.8475、Z=3.040、超過2.980311ms。外側区間は側壁も近いため、強い2経路の選択を変えず確認できる聴取点を使う。 |
| 名目固定窓組立と主要柱 | 共有Planから求めた金属框位置でも反射する。主要柱x±8.99、庭との隙間x±5、外端の外x±10.801、展示窓上下の外y=.149/3.351を除外する。光庭・上階の幅・上下端・柱・階間の除外も保持する。 |
| 反射の上限と既存bounds | 座面と同Zの試験足音による187.566msの正面反射は180ms上限で除外。Z=3.02の試験点でも、完成面以外の反射にZ>3を許可しない。反射声は2のまま。 |
| 直接音・尾部・音源 | 座面から既存空調A0への`directDistance/gain/cutoff/shelter/lateSend`を追加前の基準値と照合し、`localTailMix=.369857…`を保持する。既存生成IRの長短T20範囲も確認する。音源・IR・マスター・Listenerの更新処理を追加区間のために変えない。 |

統合時は[検証手順](../verification.md)に従い、`npm run check`、ビルド後の`npm run test:coast:browser`と`npm run test:atrium:browser`を確認する。局所の経路計算が通ることと、実際の音像・快適さは別の検証である。聴感を評価する際はヘッドホン・音量・時刻をそろえ、座面→石床→正面固定窓前→側廊→ソファの一定経路と頭の±90°回転で、静止時の足音、方向の世界固定、短い返り、クリックや急な音量変化を確認する。方位だけ180°回した時は距離・遮蔽が同じで、Listenerの向きだけが変わることを聴き比べる。快適さは専門所見と利用者評価を分ける。

## 証拠・未実施・残リスク

確認済みは、一次資料と既存音響構造の照合、共有完成面を使う反射実装、Nodeの有限面・経路・生成IRの局所回帰である。設計段階では座面経路をNode、代表的な鏡像経路をPythonでも計算した。これらの計算結果は実空間の測定値や聴感評価ではない。統合チェックの実行結果・証拠はIssue #269へ記録する。

最終アプリのブラウザ出力は、マイクを使わず`MediaStreamDestination`へ分岐して**録音取得済み**である。録音原本名は`atrium-night-walk.webm`、技術値と取得条件は`atrium-night-walk.json`に記録した。

| 録音条件・技術値 | 取得結果と評価範囲 |
| --- | --- |
| 時間帯・mix | 夜、既定mixへリセットした状態。 |
| 経路 | ソファ座位3秒→立位→庭前`(x=-2.7,z=2.2)`で+Zを向き3秒→W店前`(x=-10.8,z=-4)`で−Xを向き3秒。 |
| 出力 | 27.36秒、48kHz、2ch。デジタル振幅のRMS=.00288579、サンプルピーク=.0205811、記録されたエラー0件。これらは音圧値ではない。 |
| 分離計測の境界 | 環境音・足音・反射を含む混合出力の記録。7.026ms・2.980311msの到来や帯域別RTを、この録音から分離計測していない。 |

録音取得は、再生機器・部屋・ヘッドホンを通した聴感の評価を含まない。機器と部屋の影響、ヘッドホンでの音像・快適さ、HMD実機での頭部追従・定位、帯域別IR測定、再生系校正、利用者評価は未評価・未実施として残る。dBFSをdB SPLへ換算していない。2経路＋2尾部は角回折・曲面散乱・実材料周波数特性・隣室再流入を解かず、固定窓組立の係数も帯域・入射角・材質ごとに分離していない。14区間への反射対応は局所の整合改善であり、施設の実音圧・残響時間・情緒効果を実測で達成したという意味ではない。
