# 住戸の仕上げ材

写真由来のテクスチャは [Poly Haven の CC0 素材](https://polyhaven.com/license) を使用。配布用に WebP へ変換し、解像度を調整した。漆喰とリネンの色マップは仕上げ色を反映できるよう明度に変換した。ウォルナットの色マップは木目の濃淡と色味を調整した。

| 配布ファイル | 素材・作者 |
| --- | --- |
| `oak-{color,normal,roughness}.webp` | [Oak Wood Planks](https://polyhaven.com/a/oak_wood_planks)、Dimitrios Savva |
| `walnut-{color,normal,roughness}.webp` | [Natural Walnut Veneer](https://polyhaven.com/a/natural_walnut_veneer)、Jenelle van Heerden |
| `plaster-{color,normal}.webp` | [White Plaster 02](https://polyhaven.com/a/white_plaster_02)、Rob Tuytel |
| `linen-{color,normal}.webp` | [Rough Linen](https://polyhaven.com/a/rough_linen)、colormass（撮影）、Rico Cilliers（処理） |
