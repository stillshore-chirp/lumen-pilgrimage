# アトリウム音響の素材

`src/coast/world/atrium/atriumAudioSamples.ts` が換気の気流、店舗やカフェ裏の機器音、床材ごとの接触音を、固定の乱数シードと Web Audio の `AudioBuffer` で合成します。写真からは空間の形状と見える仕上げを参照しています。配布する音響素材はこのコードによる合成音です。

鏡像法で地上の石床、回廊の床と軒裏、壁、天井の反射を推定し、経路の長さから反射の遅れを求めます。回廊を横切る経路は減衰させ、敷物に当たる反射は高域を抑えます。 [Allen・Berkley の鏡像法](https://doi.org/10.1121/1.382599)

後期残響は開放部の1.86秒と低い天井下の0.95秒を設計値とするステレオ応答を生成します。歩行中は回廊の軒裏と敷物に近づくにつれて短い応答の比率が増えます。参考にした商業施設の測定例では、吹抜け中央が1.4秒、低い吸音天井のある飲食区画が0.91〜0.99秒で、別の飲食区画では改修で4.7秒から1.7秒へ短くなっています。設計値と混合比は、これらの実測例を参考に仮想空間用に設定しました。 [吹抜けと飲食区画の測定](https://www.mdpi.com/2076-3417/10/3/1170) · [改修前後の測定](https://www.mdpi.com/2624-599X/3/1/11)
