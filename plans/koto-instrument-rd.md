# 十三弦箏音源の研究開発

## 目的と対象範囲

[Issue #275](https://github.com/stillshore-chirp/lumen-pilgrimage/issues/275) の依頼を追跡する。基準となる実装は main `375c3b7a2d77f3cae2420e5b3ca7c2f4e8bba597`。現行の39秒の独自曲と湖畔の12スピーカーを保ち、音色・演奏表現・空間再生を分けて研究し、実際の出力で比較・改善する。旧モデルは [比較用原本](../scripts/fixtures/lakeKotoLegacy.ts) に保存する。

## 関連分野と根拠

楽器音響、弦・爪・琴柱・胴の振動、数値解析、DSP、箏の調弦・奏法、録音・権利と倫理、知覚評価、空間音響、非同期処理・性能、比較画面の操作を扱う。原理から最終出力までの対応は[音源設計](../docs/lake/koto-instrument-design.md)を正本とし、個別研究・素材記録・測定結果を参照する。資料を読んだだけ、合成できただけ、テストが通っただけでは音質を合格にしない。

## 受け入れ条件

- [x] 原典を実読し、現行の問題・仮説・モデルの適用条件を区別して設計へ反映する。
- [ ] 物理、CC0サンプル、ハイブリッドを同じ入力で実レンダーし、利用できない音域・方式も理由とともに明示する。
- [x] 39秒の独自曲、十三弦、奏法、間合い、重なりと余韻を維持・改善する。
- [x] 新規録音のCC0 1.0、出典、実演・録音・楽曲等の権利と倫理、加工・再配布を合理的に確認する。不適格なら採用しない。
- [x] CC0優先の恒久規則・証拠台帳・機械検査を既存運用へ組み込む。今回だけのCC0限定と他案件を混同しない。
- [x] 新旧・奏法・全曲・音量整合・乾音/空間の比較と条件付き評価記録を利用できる。
- [x] 12スピーカー、desktop/模擬XR、再生停止・ループ・音量・切替・資源解放、外部サービスに依存しない同梱再生を検証する。
- [x] 信号品質・理論との整合・初期化/CPU/メモリ・長時間再生を測定し、不合格を修正する。
- [ ] 標準check・関連ブラウザー・ルール検査・独立レビューを実施し、最終履歴と受け入れを照合して配送する。
- [ ] 人間による聴感評価を独立に実施する。実施できなければ最終音質は未判定、Issue全完了にはしない。

## 検証

| 条件 | 入力・環境・判定方法 | 正本・証拠 | 未確認の扱い |

| 数理・波形 | 同じ弦・強弱・奏法・seed、48 kHz基準、96 kHzとの収束も比較 | 物理研究と測定記録 | 実測校正していない物性値、数値分散、未分離のaliasを明記 |
| 方式比較 | 同じケースと曲、method共通の音量整合で強弱差を維持 | 比較manifest、raw float波形、整合済み波形 | サンプル不足を合成で埋めて純sampleと呼ばない |

## 作業上の判断

音源モデルの計算はオフラインで行い、通常の再生は同梱PCMを遅延ロードして再利用する案を性能測定で評価する。比較UIと生成音群は通常の配布入口から分離する。現行の起動プレビューや他作業treeを変更しない。関連する独立成果は責務ごとにcommitし、同じIssueから追跡する。未評価の聴感を理由に実行できる研究・実装・検証を止めない。
